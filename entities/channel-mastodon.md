# Mastodon

# Shape
Community-first. Lead with value or a real question. Chronological feed, so the post stands alone. Alt text required. Content warning for long or sensitive notes. See [[writing-for-mastodon]].

# Limits
- Common default 500 characters.
- A few CamelCase hashtags, not a wall.
- Not connected. Do not invent an instance or a handle.

# Failures
Announcement-speak. Link shorteners. Images without alt text. Growth-hacking.
