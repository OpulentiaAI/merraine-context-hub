# Shape
Hook first. One idea per post. The first 280 characters have to carry the point even if the account can write longer. A thread starts with a post that stands alone, not a table of contents. See [[writing-for-x]].

# Limits
- Free accounts cap at 280. Preview is still about 280 either way.
- Tight band around 240 to 259 is craft, not a law.
- 0 to 2 real hashtags. Links go in the first reply.
- Jeremy does not have this channel connected. Say so before drafting a send.

# Failures
"A thread on…". Engagement bait. Hashtag walls. A hook the body does not keep. Invented handles or stats.
