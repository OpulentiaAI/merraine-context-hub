# Writing the message set

Positioning first, via [[settling-positioning]]. Then one core message,
three or four pillars, proof under each, graded `proven` / `plausible` /
`assumption`.

Lead with a different benefit for CEO vs CHRO vs PE partner. Use their
words from [[customer-language-first]]. Include the objections we will
not dodge, and who should not buy.
