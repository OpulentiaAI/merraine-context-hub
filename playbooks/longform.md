# Long-form

# Job
Write the piece a thread or a note will be cut from. Lead with the
reader's problem. Do not publish.

# Process
1. Read [[icp-context]], [[jeremy-voice]], and [[channel-blog]].
2. If a fact is missing, run [[verifying-a-public-claim]]. Gaps stay gaps.
3. Structure: hook, stakes, payoff, one next step. No "in conclusion".
4. Run [[keeping-prose-clean]] and [[slop-patterns]].
5. Hand to [[review]]. `sendReady: no`.
6. If Jeremy wants it kept, write it as a Notion page. A page beats 900
   words in a chat.

# Output
A titled draft plus the gaps list. Proof we cannot cite stays `[NEED]`.

# Guardrails
- Do not name a placement or a client Jeremy has not released.
- Do not pad to a word count.
- SEO titles are optional. Voice is not.
