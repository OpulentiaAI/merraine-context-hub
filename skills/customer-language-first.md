# Customer language first

Ask Jeremy about the last placement and the last loss, not about a persona.
Read public posts for the verb they use for the job. Quote it. One quote
is an anecdote. Two independent sources is a pattern.

Compliments are noise. "I stopped waiting on the contingency firm" is a
finding. Hypothetical willingness to buy is not evidence.
