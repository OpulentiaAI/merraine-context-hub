# Evolving the ICP

Open [[icp-context]] and [[icp]]. Load the current file first. Merge. Do
not silently replace a line Jeremy agreed to.

A `[NEED]` stays empty until a cited artifact fills it. Positioning
questions go through [[settling-positioning]] first.
