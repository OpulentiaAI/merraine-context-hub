# Blog

# Shape
Lead with the reader's problem, not Merraine. Hook, stakes, payoff, one next step. Subheads that still make sense if you only read them. See [[writing-a-blog]].

# Limits
- Title about 50 to 60 characters, keyword first. Meta description about 150, mobile cuts near 120. Those are click budgets, not ranking laws.
- One H1. H2s that still make sense if you only read them. Break a section past about 300 words.
- Short paragraphs, 2 to 4 sentences. Most sentences under about 20 words.
- 3 to 5 internal links with destination-named anchors. Alt text describes the image, about 125 characters, no "image of".
- Not a magic length for the body. A quick answer can be a few hundred words. Do not pad.

# Failures
Product-first openers. "In today's fast-paced world". Padding to a word count. A placement named without Jeremy's say-so.
