# Slop patterns

# The play
Run this on **every** message any automation in this hub drafts, for any recipient.
If a note trips two or more, rewrite it.

**Instant fails**

- "I hope this message finds you well"
- "Just circling back" as the entire message
- unlock, leverage, synergy, cutting-edge, game-changer, elevate your
- "As a [title] at [company], you understand the importance of"
- A compliment with no object: "Great insights lately"
- Invented personalisation: "Loved your recent post on leadership"
- Paragraph walls on LinkedIn
- Three questions in one note
- "Quick question" followed by a paragraph that is not a question

**Soft fails, rewrite**

- Opening every note with "Noticed that..."
- Restating their About section back to them
- Our product name in a connection request
- "Would love to hop on a call" with no reason
- Stacked em dashes, emoji stacks, fake-casual "hey hey"

**Pass test.** Read it out loud. If you would be embarrassed to send it from your
own account to a peer, it fails.

# How we apply it for Merraine
Jeremy Sanchez is a talent scout writing to CEOs and CHROs. The failure mode is
worse for him than for a SaaS rep: a search firm that sounds automated signals it
will send automated candidates. Every draft passes this check before it reaches
`recognition-digest` or `signal-digest`.

Once [[email-communications-extraction]] has run, the voice profile built from his
own replied-to mail supersedes generic tone guidance. Match the man, then run this
list over the result.
