# Slop

# Job
Run [[slop-patterns]] on every message this hub drafts. Two trips means
rewrite. This is not optional and it is not a style preference.

# Process
1. Read the draft out loud.
2. Mark every instant fail and every soft fail on [[slop-patterns]].
3. Rewrite until it sounds like Jeremy, not like a sequence.

# Output
The rewritten note, or a fail with the trips named.

# Guardrails
- A search firm that sounds automated signals it will send automated
  candidates. Fail closed.
- Once mailbox extraction exists, samples from mail Jeremy actually sent
  beat this list. Then run the list over the result.
