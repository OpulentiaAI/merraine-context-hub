# Initializing the hub

Read [[hub-init]] and run it in this session.

Do not stop after a status report. Skip Spear. Extract every other
connected service. Index contacts from the Spear export and from mail
once Gmail is on. Train voice from replied-to sent mail. Create the
day-one automations Disabled. Write `init-receipt.json`.
