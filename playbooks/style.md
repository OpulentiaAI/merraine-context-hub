# Style

# Job
Keep the claim. Change the clothes. Voice, banned words, and prose
quality. Not positioning, not a new fact.

# Process
1. Read [[icp-context]] and [[jeremy-voice]]. The claim is already settled
   by [[settling-positioning]] and [[writing-the-message-set]].
2. Restyle for the destination. Email uses [[writing-in-email-style]].
   LinkedIn uses [[writing-in-linkedin-style]].
3. Run [[keeping-prose-clean]] then [[slop-patterns]].
4. Edit in passes via [[editing-the-draft]]: sense, voice, payoff, proof,
   specificity. One pass, one question.
5. Show the before and after. Do not silently replace a sentence Jeremy
   already approved.

# Output
```
# Style pass — [date]
Channel: email|linkedin
Claim (unchanged): [one line]
Before → after: [only the lines that moved]
Trips: [none | named]
```

# Guardrails
- A new number, a new proof, or a new audience is not a style pass.
  Send those back to [[research]] or [[icp]].
- Em dashes are an instant fail. Jeremy does not use them.
