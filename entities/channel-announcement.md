# Announcement

# Shape
What changed, who it affects, what to do, where to read more. Lead with the change, not the journey. "You can now…", not "we added…". See [[writing-an-announcement]] and [[announcement]].

A versioned record groups only the headings that have entries, newest first, dated `YYYY-MM-DD`: Breaking, New, Improved, Fixed. Those map to Added / Changed / Deprecated / Removed / Fixed / Security. Do not invent Tweaks or Misc.

# Limits
- Four things on a public note, and nothing else.
- One or two sentences per changelog entry. Link the deeper page.
- If action has a date, that sits near the top.
- A named placement or client stays `[NEED]` until Jeremy allows it.

# Failures
"Six months ago the team set out to…". Marketing adjectives. A commit-log dump. "Tweaks". A note written to fill a slot.
