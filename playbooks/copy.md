# Copy

# Job
Write a personalised note for every lead that cleared the cut. Then run
[[slop-patterns]]. Do not send.

# Process
1. Read the angle. If it is thin, write a shorter note. Do not decorate.
2. Draft A: recommended. Draft B: sharper contrast, same facts.
3. First sentence quotes the cited event. One question. Permission to pass.
4. 80 words for a signal opener, 60 for congratulations. Connection notes
   stay short.
5. Run [[slop-patterns]]. Two trips means rewrite.
6. `sendReady: no`.

# Output
```
# Copy pack — [date]

## [Name] — [Company]
Score: [n] · Angle: [one line]
Note:
---
[text]
---
Contrast (do not send both):
---
[text]
---
```

# Guardrails
- No fake "loved your post" unless research quoted a real post.
- If you cannot personalise without inventing, write a role-based note and
  label it `role-only`. Prefer dropping these over sending forty of them.
- Use [[jeremy-voice]]. Faith, family, and Chicago only when they are true.
