# Write the last note first

# The play
A sequence has an end. Write that last note first, because it tells you what the earlier ones are building toward. Each mail teaches one thing and asks one action. Stop when they did the thing.

# How we apply it for Merraine
[[writing-a-sequence]] owns this. Default end state is a reply or a 15-minute call. Pair with [[baur-exit-on-reply]] so a live thread kills the rest of the run.
